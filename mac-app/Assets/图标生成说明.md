# Kindle 推送图标

用代码绘制（CoreGraphics），不依赖生图模型，可以精确修改、任意尺寸清晰。

- 源码：`make_icon.swift`
- 原图：`AppIcon-source.png`（1024×1024，透明背景）
- 应用资源：`AppIcon.icns`

## 设计

- **纸色底板**：暖米白渐变，左上角有一点台灯般的柔光，呼应「把文章留给慢读」。在一排蓝色图标的 Dock 里一眼能认出来。
- **石墨色墨水屏阅读器**：标题一条、两段正文，墨水屏纸色屏幕，小尺寸下仍能看出是阅读器。
- **朱红纸飞机**：像印章一样的点睛色，从屏幕右上角飞出，下方一串点状轨迹表示无线送达。
- 底板按 Apple 图标网格：1024 画布中 824 主体、约 186 圆角，带投影。

## 重新生成

```bash
swift make_icon.swift AppIcon-source.png            # 朱红（默认）
swift make_icon.swift AppIcon-blue.png blue          # 蓝色备选
mkdir AppIcon.iconset
for s in 16 32 128 256 512; do
  sips -z $s $s AppIcon-source.png --out AppIcon.iconset/icon_${s}x${s}.png
  sips -z $((s*2)) $((s*2)) AppIcon-source.png --out AppIcon.iconset/icon_${s}x${s}@2x.png
done
iconutil -c icns AppIcon.iconset -o AppIcon.icns && rm -r AppIcon.iconset
```
