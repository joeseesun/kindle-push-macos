# 从 Mac 到 Kindle

这是一篇**公开的排版示例**，可以用于检查中文段落、标题、表格和代码的阅读效果。文章转换成 EPUB 后，仍可在 KOReader 中调整字号与页边距。

## 提示与列表

> [!tip] 先读一小段
> 如果你能看到这段文字，说明文章已经被转换并打开。提示块不需要彩色背景也能读清楚。

- [x] 准备一篇 Markdown 文章。
- [x] 转成适合阅读的 EPUB。
- [ ] 给自己留十分钟，安静地读。

## 小表格

| 内容 | 在 Kindle 上 |
| --- | --- |
| 正文 | 跟随字号重排 |
| 图片 | 限制在屏宽内 |
| 代码 | 长行允许换行 |

## 代码

```python
message = "这是一行比较长的示例代码，用来检查小屏幕上是否能够换行显示，同时保持代码本身的内容。"
print(message)
```

行内代码 `print("hello")` 和普通的 **粗体**、*斜体*、~~删除线~~都应保留。
