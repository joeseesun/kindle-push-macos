# EPUB 中文对照翻译

1. 在翻译设置中安装隔离组件（`bbook_maker==1.3.2`）。此组件与原先直接发送使用的 Python 独立，失败不影响直接发送。
2. 在「翻译服务」里选一个服务：
   - **ChatGPT**：点「用 ChatGPT 登录」，在浏览器里登录（Plus、Pro、Business 都可以）。翻译用套餐额度，不按 API 计费，一次翻译一章。登录交给 OpenAI 官方的 Codex 命令行工具（`codex login`），应用不接触登录凭证；没装的话设置里会给出安装命令 `brew install --cask codex`。
   - **词元跳动、OpenRouter**：可以点「登录…自动填入 Key」，在浏览器授权后 Key 自动填好；也可以粘贴 Key。
   - **DeepSeek、OpenAI、Gemini、Kimi、智谱、通义千问、豆包、硅基流动**：点「获取 API Key」去官网拿 Key，粘贴后按回车。
   - **Ollama、LM Studio**：本机模型，不需要 Key，正文不出本机。
   - **自定义服务**：任何兼容 OpenAI 接口的地址。
   填好 Key 后，应用会读取这个服务的模型列表，推荐模型排在前面，直接选就行；读不到时可以手动填写。API Key 保存在 macOS 钥匙串，不出现在命令参数、设置 JSON 或发布包中；已有本机 `qiaomu-llm` 的 Magpie 配置时复用同地址的钥匙串引用。
3. 拖入 EPUB，选择「中文对照版」。先试译 3 段正文（没有 `p` 段落的特殊 EPUB 请直接检查整本输出）；试译样本只保存在本机。
4. 「翻译并发送」会生成整本中文对照版，再使用原有 SSH 传输和 SHA-256 读回校验。传输失败时重试可以复用相同内容和模型设置下已完成的译本。

## 质量与速度

在「翻译设置 › 质量与速度」中调整：

- **译文风格**：自然流畅（引擎默认）、忠实准确、文学润色、技术学术。后三种作为系统提示词交给模型，用户提示词仍用引擎默认模板。改风格算作不同任务，不会复用或覆盖原风格的进度。
- **术语表**：每行一条 `原文 -> 译名`，`#` 开头为备注，最多 500 行。对应引擎的 `--glossary`；只有出现这些词的请求才带上术语，不增加其他段落的费用。改术语表也算作不同任务。
- **同时翻译**：1–4 章并行，默认 3，对应引擎的 `--parallel-workers`。费用不变，速度通常快 2–4 倍；服务限流时调低。并行数不影响译文，改了以后仍可接续原任务。并行时停止需要等当前各章收尾。试译 3 段始终单线程。
- 上下文：整本翻译继续使用 `--use_context window`，把最近几段原文和译文带入请求，保持人名和语气连贯。

## 只翻译，不发送

中英对照模式下，「先试译 3 段」右侧的箭头里有「翻译整本，只保存到本机」，快捷键 ⌥⌘↩。不需要连接 Kindle，完成后在访达中选中译本。之后再「翻译并发送」会直接复用这个译本。

## 进度与恢复

- 后台翻译保存在用户的 `Library/Application Support/KindlePush/translations`，每个任务有原书副本、引擎日志、状态和翻译检查点。不要提交或分享这个目录，它含有书籍正文。文件夹在本机，不等同于云端备份。
- 已生成 EPUB 在 `Documents/Kindle推送/已转换`。试译带「试译3段」，完整输出带「中文对照」，二者分开。
- 同一本书的原文摘要、模型地址、模型设置或试译范围改变，会创建不同任务，防止复用错误译本。
- 停止翻译后保留已写入检查点的进度。再次点击会恢复；尚未保存的当前请求可能需要重译并再次计费。
- 关闭应用时后台任务继续，但不会自动发送。重新打开、加入同一 EPUB 后可接续。任务最长运行 24 小时，到时保留检查点并停止。
- 完整输出不存在、引擎失败、无效 EPUB 或主动取消时，都不会进入自动发送。原书不会被覆盖。
- DRM 加密 EPUB 不保证可用；翻译不会解密。图片中的文字和扫描版正文不做 OCR。复杂排版、公式、人名术语和长书译文需要人工抽查。

## 数据与凭据

正文仅在用户点击试译或翻译时发往设置中的服务，按服务商 API 用量计费。界面与状态不会展示原始服务错误响应、书籍内容或密钥；本机引擎日志含正文，保存在私有任务目录。默认显式关闭模型思考，不自动切换 Pro。

应用不会把个人钥匙串项、SSH 配对、历史任务、书籍或依赖环境打入安装包。卸载应用后这些文件会保留，以便恢复；确需删除时先备份希望保留的译本和配对。

## 开发验证

运行 `python3 -m unittest discover -s wifi-push -p 'test_*.py' -v` 和 `./script/package_release.sh`。自动化覆盖试译/整本隔离、取消、失败后的旧输出清理、无效 EPUB、凭据目的地址隔离、摘要和恢复命令。真实 API、设备传输和 Kindle 打开阅读应分别记录，不能互相代替。
