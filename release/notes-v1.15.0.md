## 中文

- **翻译不再只限 EPUB**：TXT、Markdown、HTML、Word、ODT、RTF、FB2 都能译，装了 Calibre 还能译 MOBI/AZW。
- 翻译失败时说清原因和下一步：Key 不对、余额用完、被限流、模型用不了、连不上网，各有各的话。
- 翻译完或失败时发系统通知；翻译和发送期间防止 Mac 闲置睡眠。
- 开始前粗估 token，译完显示实际用量；发送时显示百分比和进度条。
- 移除书后可以撤销（⌘Z）。设置新增「存储」页，能看占用并清理。
- 修复重新发送「已转换」里的文件时多出「书名 2」；修复翻译完自动发送时取消不到。

## English

- **Translation is no longer EPUB only**: TXT, Markdown, HTML, Word, ODT, RTF and FB2 all work, and MOBI/AZW with Calibre installed.
- A failed translation now says why and what to do: bad key, no balance, rate limit, unavailable model or no network.
- System notification when a translation ends or fails, and an idle Mac no longer sleeps during translation or sending.
- Token estimate before starting and actual usage after; percent and a progress bar while sending.
- Removing a book can be undone (Cmd-Z). A new Storage tab in Settings shows disk use and clears what can go.
- Fixed a "title 2" copy when re-sending a file from the output folder, and cancelling a send that follows a translation.
