## 中文

- **按书翻译，任意语言互译，还能同时发给多台 Kindle**：拖入 EPUB 自动认出书的语言，外文书一键选对照或仅译文，每本可以单独翻成 20 种语言里的任意一种。
- 在连接面板勾选多台 Kindle，每本书都会发给每一台。某一台不在线不耽误其他几台，这本书显示「部分送达」，重试只补发给没收到的。
- 每本 EPUB 的第二行显示书的语言，行尾标签直接写产物名：中英对照、中日对照、仅日文。中文书默认不打扰，也可以随时翻成别的语言。
- 底部只留「保存到本机」和「发送到 Kindle」，左边一行说明这次会做什么。原文和要翻译的书同时进行，译完自动发送。
- 设置新增「语言」页：偏好翻译语言，以及外文书默认怎么处理。没有配对 Kindle 时，「保存到本机」是主按钮，也能当翻译工具用。
- 修复翻译和发送同时进行时底部按钮被挤坏、发送按钮上的数量看不见。
- 1.13 的设置和未完成的翻译都保留，升级后不用重新配置。发 PDF、MOBI 等原样格式的要求不变。

## English

- Translate book by book, between any languages, and send to several Kindles at once. EPUB language is detected locally; each foreign book can go side by side or translation only, into any of 20 languages.
- Tick several Kindles in the connection panel and each book goes to each. A Kindle that is away does not hold up the others: the book shows as partly delivered and a retry sends only to those that missed it.
- Each EPUB row shows its language and an output tag named after the result. Chinese books stay quiet by default and can still be translated.
- The footer is down to Save and Send, with one line saying what will happen. Originals and translations run at once; translations send when done.
- A new Language settings page sets the preferred language and the default for foreign books. With no Kindle paired, Save becomes the main button.
- Fixed footer buttons being squeezed with both queues running, and the invisible count on the send button.
- Settings and unfinished translations from 1.13 carry over.
