## 中文

- **免安装**：Python 和 Pandoc 都内置在应用里，不用装 Homebrew，也不用开终端。安装包因此变大，约 70 MB。
- 已经装好的翻译组件继续可用；它依赖的 Python 被删或升级时，应用会提示重新安装。
- 修复部分 EPUB 读不到封面，以及部分 EPUB 的长章节不分段。

## English

- **Nothing to install**: Python and Pandoc now ship inside the app, so no Homebrew or Terminal. The download grows to about 70 MB.
- An existing translation engine keeps working. If the Python it relies on was removed or upgraded, the app now says so and offers a reinstall.
- Fixed missing covers on some EPUBs, and long chapters not being split on some EPUBs.
